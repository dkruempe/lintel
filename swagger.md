### /messageQueue/{processName}/{messageQueueName}

#### GET
##### Summary

Get message queue

##### Description

Returns message queues matching the given name patterns as a JSON array. With the optional query parameters 'after' and 'limit' the result is keyset-paginated (ordered by queue name ascending) and returned as an envelope object {items, has_more, next_after}. Follow next_after to retrieve the next page.

##### Parameters

| Name | Located in | Description | Required | Schema |
| ---- | ---------- | ----------- | -------- | ------ |
| processName | path |  | Yes | string |
| messageQueueName | path |  | Yes | string |
| after | query | Exclusive lower bound on queue name; use next_after of the previous page. | No | string |
| limit | query | Maximum number of entries per page (default 100). | No | integer |

##### Responses

| Code | Description |
| ---- | ----------- |
| 200 | A successful response (array of message queues, or paging envelope when after/limit is given) |
| 400 | Bad request (invalid limit) |
| 401 | Unauthorized |
| 403 | Forbidden (wrong content type) |
| 500 | Internal server error |

##### Security

| Security Schema | Scopes |
| --------------- | ------ |
| bearerAuth |  |

### /user/users

#### GET
##### Summary

Get all users

##### Description

Returns all users as a JSON array. With the optional query parameters 'after' and 'limit' the result is keyset-paginated (ordered by user_name ascending) and returned as an envelope object {items, has_more, next_after}. Follow next_after to retrieve the next page.

##### Parameters

| Name | Located in | Description | Required | Schema |
| ---- | ---------- | ----------- | -------- | ------ |
| after | query | Exclusive lower bound on user_name; use next_after of the previous page. | No | string |
| limit | query | Maximum number of users per page (default 100). | No | integer |

##### Responses

| Code | Description |
| ---- | ----------- |
| 200 | A successful response (array of users, or paging envelope when after/limit is given) |
| 400 | Bad request (invalid limit) |
| 401 | Unauthorized |
| 403 | Forbidden (wrong content type) |
| 500 | Internal server error |

| --------------- | ------ |

## Models

### ProcessInfoDto

| Name | Type | Description | Required |
| ---- | ---- | ----------- | -------- |
| id | string | Library-internal process id | Yes |
| path | string | Executable path | Yes |
| args | array | Command line arguments | Yes |
| auto_restart | boolean | Whether the process is restarted automatically | Yes |
| restarts | integer | Restart counter since the last reset | Yes |
| max_restarts | integer | Maximum number of automatic restarts | Yes |
| process_id | integer | Operating system process id | Yes |
| runs | boolean | Whether the process is currently running | Yes |
| exit_code | integer | Last exit code, only meaningful if exit_code_valid is true | Yes |
| exit_code_valid | boolean | Whether exit_code carries a real exit code | Yes |
| group_name | string | Name of the process group | Yes |
| group_id | string | Id of the process group | Yes |
| resources_valid | boolean | Whether the resource fields below were collected | Yes |
| uptime_seconds | integer | Uptime in seconds, null if resources_valid is false | No |
| cpu_percent | number | CPU usage in percent, null if resources_valid is false | No |
| memory_bytes | integer | Resident memory in bytes, null if resources_valid is false | No |
